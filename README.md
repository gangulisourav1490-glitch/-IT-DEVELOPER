# Inventory Management System (IMS)

## 📌 Project Overview

Inventory Management System (IMS) is a web-based application developed using Flask. It helps businesses manage products, suppliers, sales, orders, and inventory efficiently.

## 🚀 Features

- User Login & Authentication
- Dashboard with Inventory Summary
- Product Management
- Supplier Management
- Sales Management
- Order Management
- Stock Monitoring
- Reports Generation
- Responsive User Interface

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/gangulisourav1490-glitch/-IT-DEVELOPER.git
```

2. Go to project folder

```bash
cd -IT-DEVELOPER
```

3. Create virtual environment

```bash
python -m venv venv
```

4. Activate virtual environment

Windows

```bash
venv\Scripts\activate
```

5. Install dependencies

```bash
pip install -r requirements.txt
```

6. Run the application

```bash
python app.py
```
